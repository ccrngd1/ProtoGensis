
──────────────────────────────── Attack surface — OpenClaw / CABAL ─────────────────────────────────
OpenClaw builds each agent's system prompt by injecting workspace bootstrap files (AGENTS.md and 
workspace context), the SOUL.md personality layer, and on-demand SKILL.md instructions; hooks add 
event-driven automations that can fire at gateway startup. Every one of these is trusted context 
assembled before the agent acts.
