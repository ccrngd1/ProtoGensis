# Partition Catalog (synthetic template)

One level only. Every entry: path, Description, Read If.

## Tree

- `docs/decisions.md`
  - Description: durable decisions with rationale, one section per decision.
  - Read If: changing or questioning an existing decision, or making a new one.
- `docs/lessons.md`
  - Description: failed approaches and what to do instead.
  - Read If: planning risky maintenance, upgrades, or bulk operations.
- `docs/conventions.md`
  - Description: non-obvious conventions the environment cannot show.
  - Read If: writing anything user-facing or touching shared infrastructure.
